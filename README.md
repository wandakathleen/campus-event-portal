# Campus Event Portal (MO-IT161 - Web Systems and Technology)

A full-stack campus event management application built for MMDC students and administrators. Features interactive event search, institutional email validation, real-time DOM updates, and persistent file storage using Node.js, Express.js, and JSON file-based persistence.

---

## ⚠️ Important: Accessing Milestone 2 (MS2) Work

The complete Milestone 2 source code and updated project files are located in the **`ms2`** branch. 

**To view the MS2 work:**
1. Click the **`main`** branch dropdown button at the top-left of the repository file list.
2. Select **`ms2`** from the dropdown menu to switch branches and view the full project files.

---

## 🚀 How to Run Locally

1. Ensure you have **Node.js** installed on your machine.
2. Clone this repository and switch to the `ms2` branch:
   ```bash
   git clone https://github.com
   cd campus-event-portal
   git checkout ms2
   ```
3. Install the project dependencies:
   ```bash
   npm install
   ```
4. Start the Express backend server:
   ```bash
   node app.js
   ```
5. Open your web browser and navigate to:
   ```text
   http://localhost:3000
   ```
